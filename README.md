# Astro data from a city balcony

Raw and linear stacks from my DWARF Mini (30 mm, 150 mm focal length), shot from a light-polluted balcony in Dnipro, Ukraine (Bortle ~6-7). Shared so anyone can try their own processing.

Each dataset is a separate [release](../../releases): the files are attached there, with acquisition details and what has or hasn't been done to the data.

## Datasets

| Target | Data | Release |
|---|---|---|
| NGC 2244 Rosette Nebula | duo-band, 2-panel mosaic, 1415 x 60 s, 10 nights, 23.6 h, linear stack | [data-ngc2244-rosette](../../releases/tag/data-ngc2244-rosette) |
